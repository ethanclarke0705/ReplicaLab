# Roadmap

| Milestone | Scope                                                 | Status   |
| --------- | ----------------------------------------------------- | -------- |
| 0         | Workspace, standards, documentation and CI            | Complete |
| 1         | Headless replication engine and correctness tests     | Complete |
| 2         | Deterministic network simulation and recovery retries | Complete |
| 3         | Accessible React/Vite playground and real scenarios   | Complete |
| 4         | IndexedDB identity, counters and history restoration  | Planned  |
| 5         | Screenshots, deployable demo and release review       | Planned  |

Stop after Milestone 3 for review; do not start persistence, deploy or push without further instruction. A local verification screenshot is included with the playground guide; deployment and release review remain Milestone 5. WebSockets, alternative resolution policies, CRDTs, benchmarks and npm publication are future considerations, not initial MVP requirements.
